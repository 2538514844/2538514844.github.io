## [DualSenseX-Steam-PC-Controller](https://github.com/TaiwanBoss/DualSenseX-Steam-PC-Controller) #1

> 一款让 PlayStation DualSense 手柄在 Steam 平台获得完整功能支持的工具。它通过自定义驱动层，实现了自适应扳机、触控板、陀螺仪等特性的原生映射。

许多 PC 玩家在 Steam 上使用 DualSense 手柄时，只能获得基础的按键识别，而索尼官方未提供完善的驱动支持。**DualSenseX** 正是为了解决这一痛点而生。它采用 **C#** 编写，通过底层钩子技术将手柄的专属协议转换为 Steam 可识别的标准输入。

<p><img src="https://opengraph.githubassets.com/1/TaiwanBoss/DualSenseX-Steam-PC-Controller" alt="DualSenseX-Steam-PC-Controller" style="max-width:100%;border-radius:8px;"></p>

项目目前收获 **99 Stars**，社区反馈积极。开发者提供了详细的安装配置指南，支持最新版 Steam 客户端。与同类工具 `DS4Windows` 相比，它的核心优势在于直接针对 Steam 平台优化，无需额外映射步骤。

未来计划包括增加蓝牙连接模式下的延迟优化，以及支持更多第三方游戏对自适应扳机的调用。适合追求 DualSense 完整体验的 Steam 玩家。

**相关链接：**
- 项目地址：[TaiwanBoss/DualSenseX-Steam-PC-Controller](https://github.com/TaiwanBoss/DualSenseX-Steam-PC-Controller)

## [female-portrait-director](https://github.com/liyue-aigc/female-portrait-director) #2

> 一个基于扩散模型的开源女性肖像生成工具，支持对五官、妆容、发型等进行细粒度控制。用户可通过文本提示与区域遮罩混合操作，生成高度定制化的人像。

随着 AI 图像生成技术普及，生成特定风格或特征的女性肖像需求激增。**female-portrait-director** 针对这一场景，提供了比通用模型更可控的解决方案。它基于 **Stable Diffusion** 进行微调，并集成了一套区域注意力引导模块。

<p><img src="https://opengraph.githubassets.com/1/liyue-aigc/female-portrait-director" alt="female-portrait-director" style="max-width:100%;border-radius:8px;"></p>

开发者开源了预训练权重与完整推理代码，目前获得 **83 Stars** 和 **21 Forks**。项目在样本生成效果上实现了对眼型、唇色、发型等 12 个维度的独立调节，精度优于同类工具如 `FaceControlNet`。

使用场景包括虚拟角色设计、时尚穿搭模拟、AI 模特生成。未来还将支持人物表情序列生成，以及与其他动画管线对接。

**相关链接：**
- 项目地址：[liyue-aigc/female-portrait-director](https://github.com/liyue-aigc/female-portrait-director)

## [xiaojianbang-stealth-hook](https://github.com/xiaojianbang8888/xiaojianbang-stealth-hook) #3

> 一个轻量级的 C 语言钩子库，专注于代码执行路径的隐蔽拦截。它采用直接内存补丁与异常处理混合技术，能在不触发常见反调试检测的前提下实现函数挂钩。

在安全研究与恶意软件分析中，代码钩子是常用技术，但传统内联钩子容易被 XFG、CFG 等保护机制识别。**xiaojianbang-stealth-hook** 通过分步写入与 CPU 缓存刷新时机控制，降低了被检测的风险。

<p><img src="https://opengraph.githubassets.com/1/xiaojianbang8888/xiaojianbang-stealth-hook" alt="xiaojianbang-stealth-hook" style="max-width:100%;border-radius:8px;"></p>

项目使用纯 **C** 编写，平台无关性较强，目前获得 **48 Stars** 和 **41 Forks**，社区活跃度较高。它支持 x86/x64 架构，并提供了 API 级别、函数级别、指令级别的三种钩子模式。

适用于游戏反外挂绕过研究、内核级监控工具的辅助开发。与 `Detours` 相比，它在隐蔽性上有显著提升，但易用性稍逊，需自行处理符号解析。

**相关链接：**
- 项目地址：[xiaojianbang8888/xiaojianbang-stealth-hook](https://github.com/xiaojianbang8888/xiaojianbang-stealth-hook)

## [ppt-image2-editable-rebuild](https://github.com/wwe-dog/ppt-image2-editable-rebuild) #5

> 一个 Python 工具，能够从 PPT 文件中提取图片并还原为可编辑的原始形状、文字与图表。它利用 `python-pptx` 库解析 OOXML 格式，通过逆向工程恢复被合并为静态图片的图层结构。

许多 PPT 文档在保存或导出时，会将组合形状、公式或矢量图渲染为位图，导致后续无法编辑。**ppt-image2-editable-rebuild** 针对这一问题，尝试从图片元数据中提取原始对象信息，并用近似形状替换。

<p><img src="https://opengraph.githubassets.com/1/wwe-dog/ppt-image2-editable-rebuild" alt="ppt-image2-editable-rebuild" style="max-width:100%;border-radius:8px;"></p>

项目采用 **Python** 实现，依赖 `Pillow` 和 `opencv-python` 进行图像分割，目前获得 **42 Stars** 和 **3 Forks**。它支持 `.pptx` 格式，可批量处理。实测对柱状图、流程图还原率约 70%，文字区域可转为文本框。

适用于需要重新排版历史演示文档的用户，尤其是企业培训和学术汇报场景。未来计划支持表格与 SmartArt 的还原。

**相关链接：**
- 项目地址：[wwe-dog/ppt-image2-editable-rebuild](https://github.com/wwe-dog/ppt-image2-editable-rebuild)

## [Chrome2api](https://github.com/xszwow/Chrome2api) #6

> 一个 C++ 工具，将 Chrome 浏览器的页面操作、Cookie 管理、网络请求拦截等功能封装为 RESTful API。通过它，外部程序可以像调用接口一样控制浏览器行为。

在自动化测试、数据采集或云渲染场景中，常需要以编程方式控制无头浏览器。但 Puppeteer 或 Selenium 依赖 Node.js 或 Java，集成成本较高。**Chrome2api** 基于 Chrome DevTools Protocol 封装，提供了轻量的 HTTP 接口。

<p><img src="https://opengraph.githubassets.com/1/xszwow/Chrome2api" alt="Chrome2api" style="max-width:100%;border-radius:8px;"></p>

项目使用 **C++** 实现，性能优于 Python 版本的类似工具，目前获得 **14 Stars** 和 **6 Forks**。它支持打开标签页、执行 JavaScript、截图、修改请求头等常用操作，响应延迟控制在 50ms 以内。

对小型团队或个人开发者而言，无需安装庞大的 Node.js 生态即可快速集成浏览器自动化。与 `chromium-net` 相比，它更侧重于高层 API 的友好性，但功能覆盖度尚有限。

**相关链接：**
- 项目地址：[xszwow/Chrome2api](https://github.com/xszwow/Chrome2api)
