## [9arm-skills](https://github.com/thananon/9arm-skills) #1

> **9arm-skills** 是一个收集了 900+ Shell 脚本的自动化技能库，涵盖系统运维、网络调试、容器管理等场景。项目以模块化方式组织脚本，用户可直接复制或管道执行，减少重复劳动。

<p><img src="https://opengraph.githubassets.com/1/thananon/9arm-skills" alt="9arm-skills" style="max-width:100%;border-radius:8px;"></p>

**9arm-skills** 的作者在日常工作中发现，许多运维任务需要反复编写类似的 Shell 命令，而网上零散的脚本又缺乏统一管理。因此，他决定将常用技能整理成一份按功能分类的脚本合集，方便自己和团队快速取用。

项目采用平铺式目录结构，每个脚本尽量保持自包含，并带有简短的注释说明。例如 `network/` 目录下包含端口扫描、路由追踪、DNS 查询等工具；`docker/` 目录则有容器日志清理、镜像批量导出等实用函数。

截至目前，**9arm-skills** 在 GitHub 上获得了 **859** 个 Star 和 **118** 个 Fork，社区反馈积极。用户可直接通过 `curl` 获取脚本内容并管道执行，降低了使用门槛。与类似的 dotfiles 仓库相比，该项目更偏向于可独立运行的“技能点”，而非环境配置。

相关链接：
- 项目地址：[thananon/9arm-skills](https://github.com/thananon/9arm-skills)

## [YellowKey-Bitlocker](https://github.com/rahul03524/YellowKey-Bitlocker) #2

> **YellowKey-Bitlocker** 是一个基于 TypeScript 开发的 BitLocker 恢复密钥管理与解密工具，提供直观的 Web 界面。用户可通过上传密钥文件或手动输入，快速解锁加密卷，同时支持密钥导出与审计日志记录。

<p><img src="https://opengraph.githubassets.com/1/rahul03524/YellowKey-Bitlocker" alt="YellowKey-Bitlocker" style="max-width:100%;border-radius:8px;"></p>

随着企业 BitLocker 部署的普及，IT 管理员经常需要在应急场景下快速查找恢复密钥。**YellowKey-Bitlocker** 项目应运而生，旨在替代传统的命令行 `manage-bde` 流程，让非技术用户也能通过浏览器操作。

核心功能包括：密钥上传解析（支持 `.txt` `.bek` 格式）、卷锁定状态预览、一键解密并提供恢复密钥副本。TypeScript 前端使用 React 构建，后端基于 Node.js，所有加密操作均在本地完成，确保密钥不过传至服务器。

该项目获得 **286** 个 Star，Fork 数为 **1**。相比微软官方提供的 BitLocker 管理工具，**YellowKey-Bitlocker** 更轻量，适合中小企业或单机场景。开发者计划后续加入 Active Directory 集成和密钥轮换提醒功能。

相关链接：
- 项目地址：[rahul03524/YellowKey-Bitlocker](https://github.com/rahul03524/YellowKey-Bitlocker)

## [Deepseek-v4-pro-app](https://github.com/MFS9628/Deepseek-v4-pro-app) #3

> **Deepseek-v4-pro-app** 是一个面向 **DeepSeek V4** 模型的桌面客户端，提供原生 GPT 风格的聊天交互界面。应用内置提示词模板、自定义 API 地址与上下文长度控制，支持离线模型调用。

<p><img src="https://opengraph.githubassets.com/1/MFS9628/Deepseek-v4-pro-app" alt="Deepseek-v4-pro-app" style="max-width:100%;border-radius:8px;"></p>

deepseek 系列模型在中文场景中表现出色，但官方并未提供独立的桌面客户端。开发者 **MFS9628** 利用 Electron 封装了一个跨平台应用，让用户可以更方便地调用部署在本地或远程的 **DeepSeek V4** 模型。

界面设计参考了 ChatGPT 的极简风格，支持 Markdown 渲染、代码高亮和对话历史导出。用户可在设置中填入自建 API 端点或使用官方 API Key，并调整 `temperature`、`max_tokens` 等参数。应用还集成了系统托盘模式，支持快速唤出对话窗口。

目前项目获得 **283** 个 Star，暂无分支。与类似开源前端（如 **Lobe Chat**）相比，**Deepseek-v4-pro-app** 专注于单一模型优化，包体积更小（约 80MB），且自带中文提示词模板，适合中文用户开箱即用。

相关链接：
- 项目地址：[MFS9628/Deepseek-v4-pro-app](https://github.com/MFS9628/Deepseek-v4-pro-app)

## [yapsnap](https://github.com/kouhxp/yapsnap) #4

> **yapsnap**（Yet Another ScreenSnap）是一个用 Python 编写的轻量级截图工具，支持矩形区域截取、全屏截图和延时截图。输出格式为 PNG/JPEG，可自动保存到用户指定目录，并提供快捷键绑定。

<p><img src="https://opengraph.githubassets.com/1/kouhxp/yapsnap" alt="yapsnap" style="max-width:100%;border-radius:8px;"></p>

日常工作中，开发者经常需要快速截图并保存到本地，而系统自带的截图快捷键往往功能有限。**yapsnap** 采用 Python 的 `pynput` 库监听全局热键，利用 `PIL`（Pillow）处理图像，总共不足 300 行代码，却实现了完整的截图工作流。

核心特性包括：可自定义快捷键（默认 `Ctrl+Shift+S`），截图后自动弹出预览窗口，支持二次编辑（绘制箭头、文字等）并保存。工具跨平台运行于 Windows、macOS 和 Linux，依赖极少。

项目目前拥有 **25** 个 Star 和 **1** 个 Fork，适合作为学习 Python GUI 编程的参考。与 **Flameshot** 等成熟工具相比，**yapsnap** 最大优势是纯 Python 实现，便于二次开发——用户可轻松扩展为 OCR 截图、颜色拾取等工具。

相关链接：
- 项目地址：[kouhxp/yapsnap](https://github.com/kouhxp/yapsnap)

## [SkillAlchemy](https://github.com/agentsope/SkillAlchemy) #5

> **SkillAlchemy** 是一个 Python 框架，用于将 AI 大模型的能力封装为可组合的“技能”模块。开发者通过 YAML 配置文件即可定义技能的工作流（链式调用、条件分支等），无需编写复杂代码。

<p><img src="https://opengraph.githubassets.com/1/agentsope/SkillAlchemy" alt="SkillAlchemy" style="max-width:100%;border-radius:8px;"></p>

随着 Agent 架构兴起，许多开发者需要将大模型与外部工具（搜索、计算器、数据库）组合。**SkillAlchemy** 提出了一种声明式技能定义方法：每个技能包含输入输出 Schema、调用提示词和依赖的 API 列表，运行时由框架自动编排。

技术方案上，项目底层基于 `instructor` 库实现结构化输出，使用 `LangChain` 的组件作为可选工具。例如定义一个“天气查询与日程安排”技能，只需在 YAML 中写明 `tools: [weather_api, calendar]`，框架便会自动规划调用顺序。

截至目前，该项目获得 **14** 个 Star。与 **AutoGen** 或 **CrewAI** 等大型框架相比，**SkillAlchemy** 更加轻量，适合个人或小团队快速实验技能组合。作者计划后续加入技能市场，允许用户分享预定义技能包。

相关链接：
- 项目地址：[agentsope/SkillAlchemy](https://github.com/agentsope/SkillAlchemy)

## [Unlocker-Phone-Tool-2026](https://github.com/DiskDaggerDwell/Unlocker-Phone-Tool-2026) #6

> **Unlocker-Phone-Tool-2026** 是一款面向 Android 手机的多合一解锁工具，支持 Bootloader 解锁、FRP 绕过、系统刷入及 Root 操作。项目提供 Windows 图形界面，内置主流品牌（小米、三星、OPPO、Vivo）的驱动与解锁脚本。

<p><img src="https://opengraph.githubassets.com/1/DiskDaggerDwell/Unlocker-Phone-Tool-2026" alt="Unlocker-Phone-Tool-2026" style="max-width:100%;border-radius:8px;"></p>

手机解锁（尤其是 Bootloader）一直是动手爱好者的刚需，但各品牌解锁流程差异极大。**Unlocker-Phone-Tool-2026** 将常见解锁步骤打包成一个工具，用户只需连接手机并选择型号，工具会自动执行备份、解锁码申请（部分品牌需手动输入）、刷入 Recovery 等步骤。

该项目基于 Python 的 `Tkinter` 构建 GUI，核心解锁逻辑依赖 `fastboot` 和 `adb` 命令行工具。开发者声称已测试了超过 50 款设备，并针对 **高通** 和 **联发科** 芯片提供了不同的刷入协议。

目前获得 **9** 个 Star 和 **3** 个 Fork。需注意此类工具存在法律风险（可能违反设备保修条款），且部分功能需要用户自行承担变砖风险。与 **XDA 开发者社区** 提供的教程相比，该工具降低了操作门槛，但建议用户在熟悉原理后再使用。

相关链接：
- 项目地址：[DiskDaggerDwell/Unlocker-Phone-Tool-2026](https://github.com/DiskDaggerDwell/Unlocker-Phone-Tool-2026)
