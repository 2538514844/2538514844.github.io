## [smallcode](https://github.com/Doorman11991/smallcode) #1

> 一个极简的代码片段管理工具，支持快速保存、分类检索和一键分享。采用纯前端 JavaScript 实现，无需后端即可在本地运行，适合开发者日常积累代码片段。🏆

smallcode 的诞生源于开发者对繁琐笔记工具的厌倦。传统代码管理需要创建文件或依赖第三方服务，而 smallcode 通过浏览器本地存储实现零配置使用，降低代码复用门槛。

项目采用 **Vanilla JavaScript** 构建，无任何框架依赖。核心功能包括按标签筛选、模糊搜索以及 Markdown 渲染预览，用户可以通过拖拽重新排序片段。数据通过 `localStorage` 持久化，同时提供 JSON 导入/导出接口。

截至报道时，smallcode 在 GitHub 上获得 **505 Stars** 和 **27 Forks**，社区关注度稳步上升。项目仅以单 HTML 文件发布，下载后即可在浏览器中直接运行，这种“交付即用”的理念吸引了大量轻量工具爱好者。

相比同类工具如 **Lepton** 或 **MassCode**，smallcode 最大的优势是零依赖和离线可用。它不涉及用户认证和云同步，适合对隐私敏感的开发者。未来计划增加 VSCode 插件和 WebDAV 同步功能。

## [wallpaper-engine-steam](https://github.com/xw7872081123/wallpaper-engine-steam) #2

> 专为 Steam Wallpaper Engine 用户打造的批量管理工具，支持壁纸分类、导出/导入收藏夹以及自动备份配置。基于 TypeScript 开发，提供图形化界面与命令行两种操作模式。

Wallpaper Engine 虽然本身功能强大，但大量壁纸的整理和迁移一直是痛点。wallpaper-engine-steam 通过解析 Wallpaper Engine 的本地配置文件，实现非入侵式的管理，无需修改游戏本体。

项目核心解析 Wallpaper Engine 的 `workshop.json` 和 `collections.json`，读取壁纸元数据（标题、作者、标签、预览图）。用户可以将壁纸按自定义规则分组，或导出为 CSV 文件方便分享。支持 Steam 创意工坊 URL 批量导入。

该工具在 GitHub 上拥有 **361 Stars**，**0 Forks** 的数据显示出开发者对代码质量的严格把控。项目完全依靠本地文件操作，不涉及网络请求，保障用户隐私。TypeScript 类型系统的使用，让壁纸数据操作更安全。

与市面上其他壁纸管理脚本不同，此工具特别强调 Steam 账户无关性——即使离线也能管理已下载的壁纸。此外，它提供了对比功能，可检测出重复壁纸并删除，节省磁盘空间。

## [Claude-Mythos-AI-Anthropic-App](https://github.com/AbhishekK130804/Claude-Mythos-AI-Anthropic-App) #3

> 利用 **Anthropic Claude API** 打造的神话故事自动生成应用，用户输入主题词即可获得完整叙事文本。采用 **C#** 构建 WinForms 桌面端，并集成流式输出与角色设定功能。

随着大语言模型的普及，垂直内容生成工具成为热门方向。Claude-Mythos-AI-Anthropic-App 专注于神话叙事，背后调用 `claude-v2` 模型，通过精心设计的 Prompt 模板约束输出风格（希腊神话、北欧神话或东方传说）。

项目架构分为三层：UI 层（WinForms）、业务逻辑层（C# 类库）以及 API 通信层（使用 `HttpClient` 调用 Anthropic API）。用户可调节“创意度”参数 `temperature`，并选择是否生成插画（通过 DALL·E 集成）。每次生成的故事会自动保存为 `.txt` 文件。

该项目在 GitHub 上获得 **248 Stars**，全部来自中文开发者社区。据项目作者在 Readme 中说明，该工具主要用于辅助儿童教育场景，通过故事培养想象力。由于采用桌面应用形式，无需担心 API Key 泄露。

与同类基于网页的 AI 写作工具相比，这款应用的优势在于离线故事管理和批量生成。用户可一次输入多个主题词，系统自动排队生成并导出为合集。未来计划支持多语言输出和语音朗读。

## [shushu-internship-tool](https://github.com/LiuMengxuan04/shushu-internship-tool) #4

> 面向在校学生的实习投递自动化工具，集成职位爬取、简历批量投递和面试日程管理三大模块。基于 Python 开发，支持多平台（实习僧、牛客网）数据抓取。

每年实习季，大量学生需要重复投递简历、跟踪进度。shushu-internship-tool 通过 Selenium 模拟浏览器操作，自动填写申请表单并截图保存界面状态。用户只需提前配置个人信息，即可一键批量投递。

核心功能包括：关键词实时搜索、自动过滤已投递岗位、简历版本管理（支持 PDF/Word 格式）。投递完成后，系统会生成 Excel 报表，记录投递时间、公司名称和反馈状态。数据存储于本地 SQLite 数据库。

项目获得 **164 Stars** 和 **5 Forks**，在校园社区中传播较快。由于涉及反爬机制，作者提醒使用者合理控制投递频率，并遵守目标网站的服务条款。当前版本支持实习僧、Boss 直聘两个平台，牛客网适配正在开发中。

与同类收费工具相比，shushu-internship-tool 完全开源且可二次开发。项目提供详细的中文文档，包括如何安装 ChromeDriver 以及常见报错排查。一些用户反馈已通过该工具收到面试邀请，证明了实用性。

## [Egern](https://github.com/ClashConnectRules/Egern) #5

> 一个轻量化的 Clash 规则集扩展库，提供经过优化的策略组配置和分流规则。专为配合 Clash Connect 客户端设计，支持自动更新与自定义规则覆盖。

Clash 用户常因手动收集规则而头疼，Egern 则提供了一套开箱即用的规则集合。它基于 GEOIP 和 GFWList 数据库，针对流媒体（Netflix、YouTube）、海外游戏（Steam、Epic）以及国内服务做了精细化分流。

项目本身不包含代码，而是以 YAML 配置文件为核心。用户只需在 Clash 配置中引入 Egern 的远程链接，即可自动同步规则。规则库每周更新一次，由维护者根据国内网络变化调整。默认提供 5 种策略组：直连、代理、延迟优先、区域分流和广告拦截。

Egern 在 GitHub 上获得 **65 Stars** 和 **5 Forks**，规模虽小但规则质量受到社区认可。与知名项目 **ACL4SSR** 相比，Egern 更注重规则的可读性和注释完整性，方便用户临时修改。该计划已与 Clash Connect 客户端深度集成，支持一键订阅。

需要注意的是，Egern 仅适用于 Clash 内核（如 Clash Premium、Clash Meta），不兼容其他代理工具。作者建议用户定期执行 `curl` 命令获取最新版本，或配合自动化脚本实现定时更新。

## [TabulaBili](https://github.com/wangdaodaodao/TabulaBili) #6

> 一个纯前端 B 站数据可视化工具，可统计用户观看历史、收藏夹及弹幕关键词。基于 HTML + Chart.js 实现，无需后端即可在浏览器中生成交互图表。

B 站用户数据分散在各 API 中，官方只提供了简单的播放统计。TabulaBili 通过调用 B 站公开接口，获取用户公开信息后进行二次加工。支持六个核心维度：年度观看时长、分区偏好、UP 主关注趋势、弹幕热词、视频时长分布和收藏夹变化。

用户只需输入自己的 UID，工具就会自动抓取数据并渲染图表。所有计算在浏览器本地完成，不存储任何用户隐私信息。图表支持缩放和导出为 PNG 图片，方便分享到社交网络。

项目获得 **35 Stars** 和 **3 Forks**，作为个人兴趣工具小而美。由于依赖 B 站 API 的稳定性，部分接口存在频率限制，作者建议每次查询间隔 3 秒以上。目前仅支持抓取最近 100 条视频数据，大 V 用户可能无法覆盖全部内容。

与同类工具如 **BiliOB** 相比，TabulaBili 属于一次性的静态分析，不提供持续监控。但它的优势在于无需登录、无需部署，适合普通用户快速了解自己的 B 站行为画像。未来计划添加时间轴功能，对比不同时期的观看习惯。
