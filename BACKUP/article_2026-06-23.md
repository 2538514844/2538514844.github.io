## [AgentSpace](https://github.com/HKUDS/AgentSpace) #1

> 香港大学团队开源的通用 Agent 交互平台，提供可视化编排界面与标准化通信协议，支持 LLM 驱动的多智能体协同任务执行。🏆

随着 LLM 能力不断突破，如何将多个模型组合为协作系统成为行业焦点。**AgentSpace** 正是为解决这一痛点而设计，它定义了一套 Agent 间通信的“语言”，让开发者无需关注底层细节即可快速搭建复杂工作流。

<p><img src="https://opengraph.githubassets.com/1/HKUDS/AgentSpace" alt="AgentSpace" style="max-width:100%;border-radius:8px;"></p>

AgentSpace 的核心组件包括 **Agent Registry**（智能体注册中心）和 **Orchestrator**（编排引擎）。前者管理所有 Agent 的生命周期，后者通过图形界面拖拽节点生成 DAG 流程。系统内置了提示链、工具调用、记忆管理等常用模板。

项目在 GitHub 上线一周即获 **225 Stars**，得到多个高校实验室关注。据开发者透露，已有团队将其用于自动化论文检索与实验方案生成。

与其他 Agent 框架（如 AutoGPT、CrewAI）相比，AgentSpace 更强调 **可观察性与调试能力**，每个节点执行过程均可实时查看中间输出。目前支持接入 OpenAI、Claude 等主流模型，并计划加入本地模型支持。

- 项目地址：[HKUDS/AgentSpace](https://github.com/HKUDS/AgentSpace)

## [meccha-chameleon-project](https://github.com/anfalalsarraf-cmyk/meccha-chameleon-project) #2

> 一个用纯 HTML/CSS/JavaScript 构建的变色龙交互动画项目，模拟了变色龙随背景切换颜色的效果，适合前端开发者学习动画与状态管理。

该项目源于作者对爬行动物色彩变化的兴趣，尝试用前端技术还原自然界的伪装机制。**meccha-chameleon-project** 没有使用任何第三方库，全部动画基于 CSS transition 和 requestAnimationFrame 实现。

<p><img src="https://opengraph.githubassets.com/1/anfalalsarraf-cmyk/meccha-chameleon-project" alt="meccha-chameleon-project" style="max-width:100%;border-radius:8px;"></p>

变色龙会根据鼠标移动、页面滚动或点击行为改变肤色。代码中内置了多套色彩方案（如森林、沙漠、夜晚等），用户也可自定义调色板。项目体积仅 3KB（不包含图片），加载极快。

尽管是创意项目，它仍在开发者社区获得 **122 Stars**。很多网友将其作为练习 DOM 事件和 CSS 变量的经典案例。作者还提供了详细的代码注释，方便初学者逐行理解。

- 项目地址：[anfalalsarraf-cmyk/meccha-chameleon-project](https://github.com/anfalalsarraf-cmyk/meccha-chameleon-project)

## [claude-code-fable-5-free-app](https://github.com/FieldofStrawberries/claude-code-fable-5-free-app) #3

> 一款利用 Claude 模型将自然语言故事转换为可运行代码的免费桌面应用，支持 C# 生成的 Windows 窗体程序，适合儿童编程启蒙。

传统编程教育往往需要先学习语法，而 **claude-code-fable-5-free-app** 尝试“故事即代码”理念：用户讲述一个故事情节（如“一只猫跳上桌子”），Claude 将其解析为对应的对象创建、属性赋值和事件绑定逻辑。

<p><img src="https://opengraph.githubassets.com/1/FieldofStrawberries/claude-code-fable-5-free-app" alt="claude-code-fable-5-free-app" style="max-width:100%;border-radius:8px;"></p>

应用基于 **WPF** 框架开发，后端调用 Anthropic Claude API。用户输入故事后，系统会先生成伪代码草图，再编译为可执行文件。项目提供 5 个预设童话示例，如《小红帽》对应一个简单的寻路程序。

该项目在 **GitHub 上获得 83 Stars**，主要来自教育工作者群体。开发者表示未来会加入 Python 生成后端，并支持导入外部故事脚本。目前免费且无需登录，但 API 调用次数受限于本地密钥配额。

- 项目地址：[FieldofStrawberries/claude-code-fable-5-free-app](https://github.com/FieldofStrawberries/claude-code-fable-5-free-app)

## [OpenFugu](https://github.com/trotsky1997/OpenFugu) #4

> 针对 ARM 边缘设备优化的轻量级 AI 推理加速器，通过量化与算子融合技术实现低延迟推理，兼容 ONNX 和 TFLite 模型。

边缘 AI 部署面临内存与算力双重约束。**OpenFugu** 借鉴了河豚（Fugu）防御机制的原理——在强约束下通过“膨胀”特定计算路径来平衡精度与速度。项目核心采用 **C++** 编写，Python 接口供上层调用。

<p><img src="https://opengraph.githubassets.com/1/trotsky1997/OpenFugu" alt="OpenFugu" style="max-width:100%;border-radius:8px;"></p>

据作者测试，将 MobileNetV2 部署在树莓派 4B 上，OpenFugu 相比 TensorFlow Lite 默认推理器可提速 **37%**，内存占用降低 **22%**。当前支持 INT8 量化，FP16 支持正在开发中。

项目获得 **54 Stars**，社区贡献了 Jetson Nano 的移植补丁。与 TensorRT 等工业级方案相比，OpenFugu 更聚焦于低功耗 Cortex-A 系列 CPU，无需专用 GPU 加速。

- 项目地址：[trotsky1997/OpenFugu](https://github.com/trotsky1997/OpenFugu)

## [wandao](https://github.com/tllovesxs/wandao) #5

> 轻量级实时图像风格迁移工具，支持从参考图提取风格并应用到新图片，提供命令行与 Web 界面两种操作方式。

设计师常需要将照片快速转换为特定画风（如水彩、油画）。**wandao** 基于 **AdaIN**（自适应实例归一化）架构，模型大小仅 8MB，可在主流笔记本上实时处理 1080p 图片。

<p><img src="https://opengraph.githubassets.com/1/tllovesxs/wandao" alt="wandao" style="max-width:100%;border-radius:8px;"></p>

区别于大厂的一键式滤镜工具，wandao 允许用户上传任意风格参考图，通过调节内容-风格权重实现微调。项目还集成了批处理脚本，可一次性处理文件夹内所有图片。

项目当前 **46 Stars**，作者在 README 中提供了 Colab 演练笔记。同类工具如 **Neural Style Transfer** 通常需要 GPU，而 wandao 在 CPU 上也能以 5-10 FPS 运行，适合预算有限的个人创作者。

- 项目地址：[tllovesxs/wandao](https://github.com/tllovesxs/wandao)

## [robot_retargeter](https://github.com/ccrpRepo/robot_retargeter) #6

> 跨形态机器人运动重映射工具，支持将人类示教动作转换为不同结构（如四足、双足、轮式）机器人的关节指令。

遥操作机器人时，操作员的人体动作很难直接映射到形状迥异的机器人上。**robot_retargeter** 提出了一种基于 **逆运动学（IK）** 的分层映射方法：首先识别人体关键点，然后根据目标机器人的运动学约束计算可行解。

<p><img src="https://opengraph.githubassets.com/1/ccrpRepo/robot_retargeter" alt="robot_retargeter" style="max-width:100%;border-radius:8px;"></p>

项目支持输入 RGB 视频（通过 OpenPose 或 MediaPipe 提取骨架），输出 URDF 格式的关节角度序列。内置 **MuJoCo** 仿真预览，可实时观察重映射效果。目前已适配 Unitree A1 四足机器人、Franka Emika 机械臂等主流硬件。

该项目获得 **45 Stars**，主要来自高校机器人实验室。与 **Rethink Robotics** 的商业方案相比，robot_retargeter 完全开源且不限制机器人型号，但需用户自行调整 IK 参数以应对不同关节限位。

- 项目地址：[ccrpRepo/robot_retargeter](https://github.com/ccrpRepo/robot_retargeter)

很多 AI 初学者被数学公式和框架配置劝退。**learn-ai-practice** 的作者主张“先跑通，再理解”，每个项目都提供完整的 Jupyter Notebook，从数据下载到模型部署一步到位。

<p><img src="https://opengraph.githubassets.com/1/i5ting/learn-ai-practice" alt="learn-ai-practice" style="max-width:100%;border-radius:8px;"></p>

项目当前 **21 Stars**，但 README 更新频繁。与其他入门资料相比，该仓库最大的特点是 **版本同步**：每个项目都注明了当时使用的库版本号，避免因环境导致报错。

- 项目地址：[i5ting/learn-ai-practice](https://github.com/i5ting/learn-ai-practice)

## [xutao-codex-image-archive](https://github.com/xutaobaogu/xutao-codex-image-archive) #8

> 基于 OpenAI Codex 的智能图像归档系统，自动为图片生成描述标签与分类目录，支持本地文件夹批量整理。

摄影师与设计师常面临海量图片管理的难题。**xutao-codex-image-archive** 调用 OpenAI Codex 的 `davinci-codex-002` 模型，对每张图片进行视觉描述并提取关键词，随后生成 YAML 元数据文件。

<p><img src="https://opengraph.githubassets.com/1/xutaobaogu/xutao-codex-image-archive" alt="xutao-codex-image-archive" style="max-width:100%;border-radius:8px;"></p>

项目支持 **CLIP** 模型进行零样本分类，用户可自定义分类标签（如“风景”“人物”“建筑”）。处理后的图片会被重命名为“日期_场景_主题_ID”格式，并建立索引 JSON。对于大文件夹（500+ 图片），系统会自动限流避免 API 超载。

该项目获得 **21 Stars**，适合需要统一管理照片的团队或个人。与 **Google Photos** 等云端方案不同，所有数据保留在本地，隐私性更好。

- 项目地址：[xutaobaogu/xutao-codex-image-archive](https://github.com/xutaobaogu/xutao-codex-image-archive)

## [Good-Tennis](https://github.com/yo-WASSUP/Good-Tennis) #9

> 基于计算机视觉的网球运动分析工具，通过手机摄像头实时识别击球动作、球速与落点，并生成数据报表。

业余网球爱好者缺乏专业教练和高速摄像设备。**Good-Tennis** 利用 **OpenPose** 人体姿态估计和 **YOLOv8** 球体检测，只需一部手机即可获得基础技术统计。

<p><img src="https://opengraph.githubassets.com/1/yo-WASSUP/Good-Tennis" alt="Good-Tennis" style="max-width:100%;border-radius:8px;"></p>

系统支持分析正手、反手、发球等 6 种基础动作，并记录每拍的时间戳和位置坐标。目前可输出 **平均球速**、**击球分布热力图** 等指标。项目提供了 Android 端 APK 体验版（需自行编译）。

该项目获得 **12 Stars**，仍处于早期阶段。与 **Playsight** 等专业系统相比，Good-Tennis 的精度受限于手机摄像头帧率（目前 30fps），但胜在完全免费且无需额外硬件。

- 项目地址：[yo-WASSUP/Good-Tennis](https://github.com/yo-WASSUP/Good-Tennis)
