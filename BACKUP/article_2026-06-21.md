## [make-look-scanned](https://github.com/overflowy/make-look-scanned) #1

> 用 Go 编写的命令行工具，可将普通图像快速转换为带有噪声、倾斜和模糊的扫描件效果。适合需要模拟实体扫描质感的文档归档或测试场景。

在数字化流程中，过于清晰的电子文档有时反而缺乏“真实感”——比如需要伪造扫描件以通过某些系统的图像识别验证，或为存档添加历史质感。**make-look-scanned** 正是为解决这类需求而生。

它使用 Go 语言实现轻量级图像处理管线，支持 JPEG/PNG 输入，提供旋转、去色、添加颗粒和随机倾斜等参数，让输出结果看起来就像刚过扫描仪。所有操作均可在终端通过一条命令完成。

<p><img src="https://opengraph.githubassets.com/1/overflowy/make-look-scanned" alt="make-look-scanned" style="max-width:100%;border-radius:8px;"></p>

该项目在 GitHub 上获得 102 Stars，虽然社区关注度不高，但其简洁实用的思路吸引了不少需要文档处理的开发者。与同类工具相比，它的优势在于纯 Go 编译的单一二进制文件，无需依赖外部图像库，跨平台部署非常方便。

适用场景包括文档测试、电子签名模拟、以及需要保留“扫描过程”痕跡的艺术创作。开发者需注意使用时应遵守相关法律法规，避免用于欺诈。

相关链接：
- 项目地址：[overflowy/make-look-scanned](https://github.com/overflowy/make-look-scanned)

## [ember-hackernews](https://github.com/DatanoiseTV/ember-hackernews) #2

> 一款用 Swift 编写的 HackerNews 第三方客户端，采用原生 iOS 界面并借鉴 Ember 设计语言。提供极简的阅读体验，支持深色模式与评论树交互。

虽然 HackerNews 官方有移动网页版，但社区一直缺少体验流畅的原生客户端。**ember-hackernews** 利用官方 REST API 实现数据获取，并用 `Swift` 结合 `UIKit` 构建了轻量级的用户界面，重点突出内容优先的设计理念。

该客户端支持主题切换（浅色/深色）、书签收藏以及完整的评论阶梯展示。界面设计从 Ember.js 的视觉风格中汲取灵感，强调卡片式排版和圆角元素，使新闻列表浏览更为舒适。

<p><img src="https://opengraph.githubassets.com/1/DatanoiseTV/ember-hackernews" alt="ember-hackernews" style="max-width:100%;border-radius:8px;"></p>

目前项目在 GitHub 上获得 72 Stars，作为个人开发者作品，其代码结构清晰，适合希望学习 Swift 客户端开发的开发者参考。与同类型客户端（如 HN Reader）相比，它更加专注于速度和简洁性，未加入过多复杂功能。

相关链接：
- 项目地址：[DatanoiseTV/ember-hackernews](https://github.com/DatanoiseTV/ember-hackernews)

## [clipforge](https://github.com/mallexibra-dev/clipforge) #3

> 基于 Python 的 AI 视频剪辑库，可自动从长视频中检测精彩片段并合成短视频。适合内容创作者、社交媒体运营者快速提取高光时刻。

短视频时代，剪辑工作已成为内容生产的核心环节，但人工筛选长视频耗时费力。**clipforge** 通过计算机视觉和语音分析技术，自动识别视频中的高潮片段（如动作、笑声或关键对话），并一键生成多段短视频。

工具采用模块化设计，支持 `ffmpeg` 作为底层编解码引擎，用户可通过 Python API 指定片段数量、时长以及输出格式。其核心算法基于场景突变检测和音频音量分析，无需 GPU 也能在 CPU 上较快运行。

<p><img src="https://opengraph.githubassets.com/1/mallexibra-dev/clipforge" alt="clipforge" style="max-width:100%;border-radius:8px;"></p>

项目在 GitHub 上获得 49 Stars，尚处于早期阶段。与类似工具（如 `auto-editor`）相比，clipforge 更加聚焦于“智能提取”而非“静音删除”，在 vlog 制作、直播回放处理等场景中潜力明显。

相关链接：
- 项目地址：[mallexibra-dev/clipforge](https://github.com/mallexibra-dev/clipforge)

## [palmier-pro-windows](https://github.com/dikurdikur/palmier-pro-windows) #4

> 面向 Windows 平台的文档处理工具集，支持 PDF 合并、分割、格式转换以及批量操作。采用 C# 与 .NET 框架，同时提供 GUI 和 CLI 双模式。

日常办公中经常需要在 PDF、Word、图片之间互转，但许多工具要么收费，要么操作繁琐。**palmier-pro-windows** 以开源方式提供一套完整的文档处理功能，包括 PDF 合并/拆分、页面提取、文本识别（OCR）以及格式互转（如 PDF → 图片）。

该工具基于 .NET 框架开发，兼容 Windows 7 及以上系统，用户可通过图形界面拖拽完成操作，也可用命令行参数实现批量脚本化处理。其 OCR 模块内嵌 Tesseract 引擎，支持中文识别。
