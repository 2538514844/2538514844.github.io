## [Lossless-Scaling](https://github.com/resonancegnatassess/Lossless-Scaling) #1

> 一个宣称实现“无损缩放”的 Python 图像处理项目，通过频域分解和子像素重建在放大时不引入伪影。该仓库上线后迅速获得 142 颗星，标志着超分辨率领域对无信息损失方法的迫切需求。

<p><img src="https://opengraph.githubassets.com/1/resonancegnatassess/Lossless-Scaling" alt="Lossless-Scaling" style="max-width:100%;border-radius:8px;"></p>

传统插值算法（如双三次）或 AI 超分模型在放大图像时往往会产生模糊、锯齿或纹理幻觉。**Lossless-Scaling** 的开发者认为，只要输入图像满足一定的带限条件，理论上可以实现完全可逆的放大。该项目基于零相位滤波与局部离散余弦变换（DCT）设计算法，避免了信息丢失。

项目采用纯 **Python** 实现，依赖 `numpy` 与 `scipy`，没有调用深度学习库。其核心思路是将图像分解为低频和高频分量，分别进行整数倍放大后再融合。据仓库文档称，在 2 倍放大下，PSNR 可保持 50 dB 以上，接近理论无损上限。

目前该仓库已收获 142 颗星与 0 个 Fork，社区关注点集中在“无损”声明的验证上。开发者提供了对比测试脚本和一组测试图像，用户可通过 `pip install lossless-scaling` 安装试用。与 `Real-ESRGAN` 等 AI 方案相比，Lossless-Scaling 的优势在于无需 GPU 和训练数据，但在大倍数放大时仍需解决频域泄漏问题。

相关链接：
- 项目地址：[resonancegnatassess/Lossless-Scaling](https://github.com/resonancegnatassess/Lossless-Scaling)

## [Wallpaper-Engine](https://github.com/wallpapers-engine/Wallpaper-Engine) #2

> 一个用 TypeScript 编写的跨平台动态壁纸引擎，支持视频、网页和交互式 3D 场景作为桌面背景。上线 106 颗星，开发者称其为“无需 Steam 收费版的开源替代”。

<p><img src="https://opengraph.githubassets.com/1/wallpapers-engine/Wallpaper-Engine" alt="Wallpaper-Engine" src="https://opengraph.githubassets.com/1/wallpapers-engine/Wallpaper-Engine"></p>

长期以来，Windows 上主流的动态壁纸工具要么需要购买商业软件（如 Wallpaper Engine），要么功能单调。**Wallpaper-Engine** 试图用 Electron 与 Node.js 后端构建一个完全免费、跨平台（Windows + macOS + Linux）的方案，支持从本地文件或 URL 加载壁纸内容。

该工具基于 `TypeScript` 实现主进程，渲染层使用 Chromium 嵌入式框架。用户可以通过拖放 `.mp4`、`.webm` 或 `.html` 文件到窗口来设置壁纸。项目还内置了简单的脚本系统，允许用户用 JavaScript 定义壁纸的时间、天气响应行为。

仓库提供了约 20 个示例壁纸，包括粒子系统、时钟动画和直播流嵌入。截至目前获得 106 颗星，尚未有 Fork。与 Steam 版 Wallpaper Engine 相比，这款开源替代支持更广泛的平台，但缺乏社区市场。开发者计划未来加入壁纸订阅源和性能监控功能。

相关链接：
- 项目地址：[wallpapers-engine/Wallpaper-Engine](https://github.com/wallpapers-engine/Wallpaper-Engine)

## [Todo-Tree-Next](https://github.com/real-Elysia886/Todo-Tree-Next) #3

> 一款基于 JavaScript 开发的树形待办事项应用，特色是无限级嵌套子任务和可视化拖拽排序。获得 64 颗星，3 个 Fork，适合追求结构化任务管理的用户。

<p><img src="https://opengraph.githubassets.com/1/real-Elysia886/Todo-Tree-Next" alt="Todo-Tree-Next" src="https://opengraph.githubassets.com/1/real-Elysia886/Todo-Tree-Next"></p>

传统的线性待办清单（如 Todoist、Microsoft To Do）在处理复杂项目时常常因缺乏层次结构而显得笨拙。**Todo-Tree-Next** 采用树形数据结构存储任务，允许用户将任意任务设置为父节点，下挂无限子任务，从而精确映射工作分解结构（WBS）。

前端基于 **Vue 3** 与 `vue-draggable-next` 库，实现平滑的拖拽重排。数据持久化使用浏览器 `localStorage`，支持导入/导出 JSON。按不同状态（待办、进行中、已完成）分区显示，并提供番茄钟计时器集成。第三方开发者可通过插件接口扩展功能。

项目在 GitHub 上获得 64 颗星，3 个 Fork。用户评论普遍认可其交互流畅度和 `CodeMirror` 集成的 Markdown 任务备注功能。与 `Trello` (看板) 或 `org-mode` (Emacs) 相比，Todo-Tree-Next 在轻量级与可移植性之间取得了平衡，但缺乏多人协作能力。

相关链接：
- 项目地址：[real-Elysia886/Todo-Tree-Next](https://github.com/real-Elysia886/Todo-Tree-Next)

## [Spiderbrain-V3](https://github.com/SaroirCommunity/Spiderbrain-V3) #4

> 第三代爬虫框架，侧重 AI 驱动的数据解析与反爬对抗。以 26 颗星启动，内置浏览器自动化与智能验证码识别模块。

<p><img src="https://opengraph.githubassets.com/1/SaroirCommunity/Spiderbrain-V3" alt="Spiderbrain-V3" src="https://opengraph.githubassets.com/1/SaroirCommunity/Spiderbrain-V3"></p>

网络爬虫正面临越来越复杂的反爬机制：动态渲染、滑动验证码、人机识别。**Spiderbrain-V3** 提出“爬虫智能化”理念，整合了 `Puppeteer` 浏览器模拟、`OCR` 与 `TensorFlow.js` 轻量模型，用于自动化识别验证码并处理登录态。

项目主体使用 **JavaScript**（Node.js）编写，配置灵活。用户只需提供目标 URL 和模板选择器，框架即可自动调度请求、渲染页面并提取结构化数据。内置的“AI 解析器”可以通过少量样本学习字段定位规则，减少手动编写 XPath 的工作。

GitHub 上显示 26 颗星与 3 个 Fork。对比老牌框架 `Scrapy` 或 `Crawlbase`，Spiderbrain-V3 的优势在于集成度——开箱即用且无需额外服务。但开发者坦言其 AI 模块目前仅支持简单验证码，复杂滑动组仍需配合第三方打码服务。

相关链接：
- 项目地址：[SaroirCommunity/Spiderbrain-V3](https://github.com/SaroirCommunity/Spiderbrain-V3)

## [Anima-Artist-Mixer](https://github.com/An1X3R/Anima-Artist-Mixer) #5

> 一款动画艺术风格混合器，通过 **GAN** 技术将不同画风（水彩、赛璐璐、厚涂）按权重融合到一张图像上。初创项目，收获 11 颗星。

<p><img src="https://opengraph.githubassets.com/1/An1X3R/Anima-Artist-Mixer" alt="Anima-Artist-Mixer" src="https://opengraph.githubassets.com/1/An1X3R/Anima-Artist-Mixer"></p>

近年来风格迁移工具多集中于写实照片与名画之间的转换，而对二次元、插画风格间的混合需求日益增长。**Anima-Artist-Mixer** 专为动画艺术家设计，允许用户上传一张底图，然后选择多个参考图（如宫崎骏的“水彩风”与新海诚的“柔光风”），通过预训练的 `AdaIN` 模块输出混合结果。

项目基于 **Python** 与 `PyTorch`，附带几个轻量预训练模型（约 50 MB）。它提供了 Gradio 网页界面，用户可滑动滑块控制每种风格的贡献比例。技术文档解释了其采用的多风格权重归一化方法，避免混合时出现色彩崩塌。

尽管仅有 11 颗星，该项目在 Reddit 的 `r/StableDiffusion` 社区引起过小范围讨论。其定位区别于 `Stable Diffusion` 的 prompt 叠加，更适合需要精确控制风格参数的专业原画师。未来计划加入批处理与风格缓存功能。

相关链接：
- 项目地址：[An1X3R/Anima-Artist-Mixer](https://github.com/An1X3R/Anima-Artist-Mixer)

## [tianming-skill](https://github.com/zy-zmc/tianming-skill) #6

> 国产游戏《天明》的技能模拟器，完全由 **PowerShell** 脚本实现，支持技能数值计算与配装推荐。获得 26 颗星与 5 个 Fork。

<p><img src="https://opengraph.githubassets.com/1/zy-zmc/tianming-skill" alt="tianming-skill" src="https://opengraph.githubassets.com/1/zy-zmc/tianming-skill"></p>

《天明》是一款国产回合制角色扮演游戏，其技能系统极度复杂，涉及多个属性堆叠与隐藏系数。**tianming-skill** 的开发者利用 PowerShell 强大的对象管道能力，将游戏内所有技能、装备、天赋数据解析为 JSON 配置文件，然后通过脚本模拟不同加点方案下的输出期望。

该项目未使用任何 UI 框架，直接通过控制台输出文本表格，支持按角色、流派、等级三种维度计算。脚本还集成了基于贪心算法的装备推荐模块，能快速找到最大化伤害的搭配。

仓库显示 26 颗星、5 个 Fork，在同人游戏工具中属于中等热度。相比其他基于 Excel 或 C# 的模拟器，使用 PowerShell 的好处是零依赖：用户只需在 Windows 上运行 `.ps1` 文件。社区贡献者已补充了最新版本的天赋数据，项目持续维护。

相关链接：
- 项目地址：[zy-zmc/tianming-skill](https://github.com/zy-zmc/tianming-skill)
