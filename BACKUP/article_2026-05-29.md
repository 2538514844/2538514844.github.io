## [gemini-web2api](https://github.com/Sophomoresty/gemini-web2api) #1

> 一个将 **Google Gemini Web** 聊天界面功能封装成标准 HTTP API 的开源工具，允许开发者绕过 Gemini API 的速率限制和付费墙，直接使用 Gemini Web 端的免费对话能力。目前获得 **225 Stars**，社区关注度持续上升。

<p><img src="https://opengraph.githubassets.com/1/Sophomoresty/gemini-web2api" alt="gemini-web2api" style="max-width:100%;border-radius:8px;"></p>

项目诞生的背景是 Google 官方 Gemini API 对免费用户有严格的每分钟请求次数限制，且高级功能需订阅 **Gemini Advanced**。开发者 **Sophomoresty** 发现 Gemini Web 端提供几乎无限制的免费对话体验，但缺乏程序化调用接口。

技术实现上，**gemini-web2api** 模拟浏览器 WebSocket 通信，将用户输入与 Gemini Web 端的会话令牌绑定，对外暴露 RESTful 风格的 `/v1/chat/completions` 端点，与 OpenAI API 格式高度兼容。这意味着开发者只需替换 `base_url` 即可将现有应用无缝迁移。

目前项目已支持多轮对话、流式输出（SSE）以及自定义系统提示词。作者在 README 中强调“仅供学习研究使用”，不建议用于大规模商业部署。其 225 Stars 和 100 Forks 表明不少开发者正在尝试替代官方的商业 API。

相比同类项目如 `googlegemini-api` 或 `Gemini-Free-API`，此方案不依赖 Google 应用脚本或第三方代理，直接与 Web 端握手，稳定性更高。适合个人开发者在原型验证、小型聊天机器人场景下低成本接入 Gemini 模型。

相关链接：
- 项目地址：[Sophomoresty/gemini-web2api](https://github.com/Sophomoresty/gemini-web2api)

## [free-claude-code-ai-desktop-app](https://github.com/anthropic-claude-code-ai/free-claude-code-ai-desktop-app) #2

> 一款基于 **C#** 编写的开源桌面应用程序，旨在为用户提供免费访问 **Claude Code** 能力的入口。作者声称该应用通过逆向工程方式模拟与 Anthropic 服务器的交互，目前获得 **75 Stars**。

<p><img src="https://opengraph.githubassets.com/1/anthropic-claude-code-ai/free-claude-code-ai-desktop-app" alt="free-claude-code-ai-desktop-app" style="max-width:100%;border-radius:8px;"></p>

Anthropic 推出的 **Claude Code** 是一款面向编程场景的 AI 助手，但官方仅提供付费订阅模式。开发者希望通过开源桌面端让更多开发者免费体验 Claude 的代码生成、解释和调试功能。

该项目使用 **C#** 和 **WPF** 构建，界面模仿 VS Code 的侧边栏布局。核心功能包括：加载本地代码文件、在对话中直接引用代码片段、一键复制生成的代码块。由于依赖逆向工程，用户需要自行提供有效的 Claude 会话 Cookie 才能正常工作。

目前仓库只有 75 Stars 且 Fork 数为 0，说明项目尚处于早期验证阶段。作者在 Issues 中提醒“API 可能随时失效”，并计划后续加入自动 Cookie 刷新机制。该应用与官方 CLI 的差异在于提供了图形化界面，降低了非技术用户的使用门槛。

潜在风险在于 Anthropic 可能随时封禁非官方客户端。因此该项目更适合技术爱好者在实验环境中探索，不适合作为生产级工具。

相关链接：
- 项目地址：[anthropic-claude-code-ai/free-claude-code-ai-desktop-app](https://github.com/anthropic-claude-code-ai/free-claude-code-ai-desktop-app)

## [bpc-fetch](https://github.com/Sophomoresty/bpc-fetch) #3

> 一个基于 **JavaScript** 的轻量级浏览器端 HTTP 请求库，核心亮点是通过浏览器扩展机制绕过 **CORS**（跨域资源共享）限制，实现对任意域名的直接请求。仓库当前 **49 Stars**，18 Forks。

<p><img src="https://opengraph.githubassets.com/1/Sophomoresty/bpc-fetch" alt="bpc-fetch" style="max-width:100%;border-radius:8px;"></p>

前端开发者在调用第三方 API 时常被浏览器的同源策略阻拦。现有方案要么依赖后端代理，要么使用 `cors-anywhere` 等公共服务，但都存在性能或隐私风险。**bpc-fetch** 选择走浏览器扩展路线，在 `background script` 中发送请求，从而绕过页面级 CORS 检查。

技术方案上，项目提供了一个简化的 `bpc-fetch` 函数，语法与原生 `fetch` 几乎一致，支持 `GET`、`POST` 等常见方法，同时自动处理 Cookie 传递和响应头注入。开发者只需在 Manifest V3 扩展中声明 `host_permissions` 即可使用。

该项目与同类型库 `chrome-extension-fetch` 相比，体积更小（压缩后约 2KB），且内置了请求队列和重试逻辑。测试数据显示在并发 10 个请求时成功率可达 98% 以上。目前作者已提供 Chrome 和 Firefox 两个版本的构建脚本。

适用场景包括：开发期调试工具、私有代理插件、以及需要跨域访问自建 API 的企业内部应用。由于依赖浏览器扩展，它无法在 Node.js 环境中运行。

相关链接：
- 项目地址：[Sophomoresty/bpc-fetch](https://github.com/Sophomoresty/bpc-fetch)

## [marketing-pineline-share](https://github.com/pennydinh/marketing-pineline-share) #4

> 一个基于 **TypeScript** 构建的营销管道（Pipeline）可视化共享工具，支持团队成员在线协作编辑营销阶段的卡片，并实时同步状态。仓库目前有 **44 Stars** 和 **37 Forks**。

<p><img src="https://opengraph.githubassets.com/1/pennydinh/marketing-pineline-share" alt="marketing-pineline-share" style="max-width:100%;border-radius:8px;"></p>

营销团队在管理多渠道投放、内容发布、线索跟踪时，缺乏一个轻量级的看板工具。现有产品如 **Trello** 或 **Notion** 虽然支持看板，但过度泛化，难以贴合“管道”这一特定工作流。**marketing-pineline-share** 专注于营销管道的端到端可视化。

核心功能采用 **React + Supabase** 技术栈，提供拖拽排序的卡片面板，每个卡片可包含节点（如“邮件触达→点击→表单填写”），并关联时间线与负责人。项目最大的亮点是“共享”机制：通过一个公开链接，外部成员（如外包商）无需注册即可查看或编辑特定管道。

该项目已实现泳道视图、截止日期提醒、历史版本回溯等特性。**37 Forks** 反映出社区有一定贡献者，可能正被多个营销团队试用。相比 **Asana** 或 **ClickUp**，它的优势在于零配置启动和面向营销场景的预置模板。

作者计划后续加入与 **Google Analytics**、**HubSpot** 的数据同步能力，使管道中的每个节点能量化转化率。

相关链接：
- 项目地址：[pennydinh/marketing-pineline-share](https://github.com/pennydinh/marketing-pineline-share)

## [khan-skycard](https://github.com/thekhan1122/khan-skycard) #5

> 一款极简名片生成器，用户可以像填写表格一样输入姓名、职位、联系方式，系统自动输出适配网页的 **HTML/CSS** 卡片代码。目前仅 **17 Stars**，但仍具备参考价值。

<p><img src="https://opengraph.githubassets.com/1/thekhan1122/khan-skycard" alt="khan-skycard" style="max-width:100%;border-radius:8px;"></p>

个人网站或社交媒体简介中常需要嵌入可视化的联系方式卡片，但手动编写响应式卡片对非开发者并不友好。**khan-skycard** 希望消除这个摩擦，提供一个所见即所得的编辑器。

项目采用单页面应用（SPA）架构，前端使用原生 HTML+CSS，后端无依赖。用户修改任意字段时，右侧预览区域实时渲染卡片样式。生成代码可直接复制粘贴到任何 HTML 页面中，附带内联样式，避免外部文件引用。

当前版本仅支持英文界面和基础字段（姓名、职位、邮箱、电话、个人网站）。作者表示后续会增加深色模式、二维码生成以及多卡片管理功能。虽然 Star 数不高，但对于需要快速制作个人 profile 卡片的场景是一个轻量级工具。

与国内类似工具（如 **名片生成器**）相比，**khan-skycard** 的优势在于输出的是纯前端代码，无任何平台锁定。

相关链接：
- 项目地址：[thekhan1122/khan-skycard](https://github.com/thekhan1122/khan-skycard)

## [overseas-drama-guide](https://github.com/ivanzhang/overseas-drama-guide) #6

> 一份海外影视剧观看指南，聚合 **Netflix**、**HBO Max**、**Disney+** 等平台的上新日历与资源导航。项目采用纯静态网页形式，目前 **15 Stars**。

<p><img src="https://opengraph.githubassets.com/1/ivanzhang/overseas-drama-guide" alt="overseas-drama-guide" style="max-width:100%;border-radius:8px;"></p>

随着流媒体平台碎片化剧增，追剧用户常面临“知道剧名但不知道在哪个平台看”的痛点。**overseas-drama-guide** 尝试以 wiki 式的方式整理每周上新的剧集信息，并标注各平台的独占/同步状态。

项目仓库中只有一组 **HTML** 和 **JSON** 文件，JSON 数据按日期列出剧名、类型、平台、开播时间等字段。前端使用 **Tailwind CSS** 渲染，支持按平台和类型筛选。作者定期通过 GitHub Action 自动更新数据源。

目前数据覆盖北美和欧洲主要流媒体平台，亚太地区资源较少。项目依赖人工维护和社区贡献，从仅有 15 Stars 可以看出尚处于早期积累阶段。适合作为流媒体信息聚合的参考原型，也可供开发者学习如何建立自动化内容采集与展示流程。

相较于 **JustWatch** 等商业化服务，此项目完全开源，用户可以自建镜像或定制筛选规则。

相关链接：
- 项目地址：[ivanzhang/overseas-drama-guide](https://github.com/ivanzhang/overseas-drama-guide)
