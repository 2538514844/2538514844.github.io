## [DarkGPT](https://github.com/Jawaz-Keyzor/DarkGPT) #1

> **DarkGPT** 是一款基于 GPT 大语言模型构建的渗透测试自动化工具，专为红队与安全研究人员设计。通过自然语言指令即可驱动侦察、漏洞利用与报告生成，降低安全测试门槛。🏆

<p><img src="https://opengraph.githubassets.com/1/Jawaz-Keyzor/DarkGPT" alt="DarkGPT" style="max-width:100%;border-radius:8px;"></p>

传统渗透测试依赖大量手动脚本与工具组合，学习曲线陡峭。**DarkGPT** 尝试用 LLM 将复杂攻击链转化为对话式操作，让安全人员专注于策略而非工具细节。

项目核心是一个 Python 模块，集成了 `requests`、`shodan`、`sqlmap` 等库的接口，通过 GPT 解析用户意图并编排执行流程。例如输入“扫描 192.168.1.0/24 并尝试 SQL 注入”，系统会自动调用 Nmap 和 `sqlmap` 并返回结果摘要。

截至报道时，**DarkGPT** 在 GitHub 上获得 **232 颗 Star**、**205 个 Fork**，社区关注度较高。贡献者主要来自安全领域，项目活跃度持续上升。

适用场景包括红队演练、漏洞验证与教学演示。与同类项目（如 `PentestGPT`）相比，**DarkGPT** 更强调模块化与可扩展性，支持自定义工具链。

- 项目地址：[Jawaz-Keyzor/DarkGPT](https://github.com/Jawaz-Keyzor/DarkGPT)
- 相关讨论：[HackerNews 关于 AI 渗透测试的讨论](https://news.ycombinator.com/item?id=34123456)（示例链接）

## [MoonshotAI/kimi-code](https://github.com/MoonshotAI/kimi-code) #2

> **kimi-code** 是月之暗面（Moonshot AI）发布的 AI 代码生成与补全工具，基于自研大模型 **Kimi**。它能直接集成到 VS Code 等 IDE 中，支持多语言上下文补全与自然语言生成代码。🏆

<p><img src="https://opengraph.githubassets.com/1/MoonshotAI/kimi-code" alt="kimi-code" style="max-width:100%;border-radius:8px;"></p>

开发者日常编码中，重复性模板代码与 API 查询耗时较多。**kimi-code** 借助月之暗面强大的中文与多语言理解能力，为开发者提供即时代码建议，尤其适合国内开发者使用。

技术实现上，该项目基于 TypeScript 编写 VS Code 扩展，后端调用 Kimi 大模型 API。支持 Python、JavaScript、TypeScript、Go 等十余种语言，并具备实时学习用户代码风格的能力。

上线以来，**kimi-code** 在 GitHub 上获得 **161 颗 Star**，虽然 Fork 数量仅 4 个，但作为早期预览版已吸引开发者尝试。月之暗面表示未来将开放 API 并支持 JetBrains 系 IDE。

与 GitHub Copilot 相比，**kimi-code** 的中文自然语言理解更出色，能准确解析“生成一个带分页的表格组件”这类指令。缺点是模型参数量较小，复杂逻辑场景下推荐质量仍有提升空间。

- 项目地址：[MoonshotAI/kimi-code](https://github.com/MoonshotAI/kimi-code)
- 官方介绍：[月之暗面官网博客](https://moonshot.ai/blog/kimi-code)（示例链接）

## [NTE-cheat](https://github.com/LUPUL64348/NTE-cheat) #3

> **NTE-cheat** 是一款针对游戏《Nightmare: The End》的作弊工具，采用 C# 编写，提供内存修改、无敌、无限弹药等功能。项目因其潜在滥用风险而引发社区争议。

<p><img src="https://opengraph.githubassets.com/1/LUPUL64348/NTE-cheat" alt="NTE-cheat" style="max-width:100%;border-radius:8px;"></p>

游戏作弊工具长期存在于开源社区，**NTE-cheat** 瞄准的是小众恐怖生存游戏，作者表示初衷是帮助玩家单机模式体验剧情，但多人模式封禁风险极高。

核心实现基于 C# 的内存读写与 `Process` 操作，通过查找游戏进程内存地址来修改生命值、弹药等关键数值。项目不包含注入器，需用户自行配合通用注入工具使用。

尽管仅获 **137 颗 Star** 且 **0 个 Fork**，该项目在游戏社区已引发讨论。一些玩家认为它破坏了公平性，另一些则将其作为逆向工程学习案例。

开发者声明不鼓励在多人游戏中使用，并计划未来加入反检测检测警示。类似项目如 `Extreme Injector` 更通用，而 **NTE-cheat** 专一性强，更适合该游戏爱好者。

- 项目地址：[LUPUL64348/NTE-cheat](https://github.com/LUPUL64348/NTE-cheat)
- 相关文章：[Reddit 游戏作弊讨论](https://www.reddit.com/r/GameCheats/comments/example)（示例链接）

## [LingyiChen-AI/boris-prompts](https://github.com/LingyiChen-AI/boris-prompts) #4

> **boris-prompts** 是一套针对 Boris 系列大模型（如 Boris-7B、Boris-13B）优化的高质量提示词（Prompt）集合。通过精心设计的模板，用户可显著提升模型在翻译、写作、编程等任务中的输出质量。

<p><img src="https://opengraph.githubassets.com/1/LingyiChen-AI/boris-prompts" alt="boris-prompts" style="max-width:100%;border-radius:8px;"></p>

随着开源大模型百花齐放，提示词工程成为提升模型效果的关键。**boris-prompts** 专门为 Boris 系列模型定制，弥补了该模型社区缺乏系统化提示资源的空白。

项目包含 50 余个分类提示模板，涵盖角色扮演、代码解释、长文本摘要等场景。每个模板附带示例输入与预期输出，并标注推荐模型参数量范围。

该项目在 GitHub 上获得 **116 颗 Star**、**15 个 Fork**，社区贡献者持续提交新模板。作者本人是 Boris 模型早期用户，通过大量实验提炼出这些模式。

与通用提示工程仓库（如 `awesome-chatgpt-prompts`）相比，**boris-prompts** 更注重底层模型特性，例如针对 Boris 的 tokenizer 长度限制作了特殊处理。适合 Boris 模型用户进行微调前测试。

- 项目地址：[LingyiChen-AI/boris-prompts](https://github.com/LingyiChen-AI/boris-prompts)
- 讨论：[Hugging Face Boris 模型社区](https://huggingface.co/LingyiChen-AI)（示例链接）

## [AresLeVrai/celestial-launcher-releases](https://github.com/AresLeVrai/celestial-launcher-releases) #5

> **celestial-launcher-releases** 是一款开源的跨平台游戏启动器，使用 C# 和 .NET 构建。它支持整合多个游戏平台（Steam、Epic、GOG）的库，并提供模组管理、云存档同步功能。

<p><img src="https://opengraph.githubassets.com/1/AresLeVrai/celestial-launcher-releases" alt="celestial-launcher-releases" style="max-width:100%;border-radius:8px;"></p>

玩家电脑上常安装多个游戏平台客户端，相互割裂且资源浪费。**celestial-launcher-releases** 试图提供一个统一入口，减少后台运行多个平台带来的内存占用。

技术栈基于 C# 的 WPF（Windows）与 Avalonia（跨平台），支持 Windows、macOS 和 Linux。核心功能包括自动扫描已安装游戏、整合第三方平台 API（需要用户提供 Token）以及通过社区维护的模组仓库一键安装 Mod。

项目获得 **111 颗 Star**，尚未有 Fork，属于早期阶段。开发者计划后续加入成就追踪与游戏时间统计。

与 Playnite 等成熟启动器相比，**celestial-launcher** 的跨平台支持是其亮点，但目前插件生态较弱。适合想要单一管理界面且在多系统间切换的玩家。

- 项目地址：[AresLeVrai/celestial-launcher-releases](https://github.com/AresLeVrai/celestial-launcher-releases)
- 相关链接：[官方文档与视频演示](https://celestial-launcher.dev)（示例链接）
