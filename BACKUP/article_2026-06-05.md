## [smart-home-button](https://github.com/Jasionf/smart-home-button) #1

> 一个基于 ESP8266/ESP32 的智能家居物理按钮，通过 Wi-Fi 连接 MQTT 服务器，可自定义触发任意家庭自动化场景。主打低成本、零代码配置，适合 DIY 智能家居入门用户。

该项目源自作者对“智能家居反人性”的反思：手机 App 控制灯光需要解锁→找 App→点按，不如物理按键直觉。**smart-home-button** 采用 C++ 编写固件，支持长按、短按、双击等多种手势，每个手势可映射到不同的 MQTT 主题。

<p><img src="https://opengraph.githubassets.com/1/Jasionf/smart-home-button" alt="smart-home-button" style="max-width:100%;border-radius:8px;"></p>

硬件兼容 **NodeMCU**、**ESP32 DevKit** 等常见开发板，物料成本约 30 元人民币。固件通过 Web 配置界面完成 Wi-Fi 和 MQTT 设置，无需编写代码。目前获得 124 个 Star，社区关注度稳步增长。

与市面上的 **Flic** 等商业按键相比，smart-home-button 完全开源，用户可自由修改代码以适配本地 Home Assistant、OpenHAB 等平台。适合智能家居爱好者在客厅、床头部署实体快捷开关。

相关链接：
- 项目地址：[Jasionf/smart-home-button](https://github.com/Jasionf/smart-home-button)

## [meatshell](https://github.com/jeff141/meatshell) #2

> 用 Rust 编写的全新 Unix Shell 替代品，强调执行速度与内存安全。提供类 Bash 语法，支持管道、重定向、作业控制，同时避免传统 Shell 常见的内存泄露和竞态条件。

Shell 作为命令行核心工具，长久以来被 **Bash**、**Zsh** 统治，但它们用 C 编写，内存安全问题频发。**meatshell** 选择 Rust，利用所有权模型从编译器层面消除空指针和缓冲区溢出。作者在 README 中称“目标不是功能最多，而是最稳定”。

<p><img src="https://opengraph.githubassets.com/1/jeff141/meatshell" alt="meatshell" style="max-width:100%;border-radius:8px;"></p>

核心功能包括：命令历史、自动补全、环境变量管理、脚本执行。目前支持 Linux 和 macOS，Windows 支持正在开发。项目发布 2 周即获得 120 个 Star，Forks 17 个，在 Rust 社区引起讨论。

与 **Nushell** 等现代 Shell 相比，meatshell 更强调“兼容性”——它直接解析 Bash 语法，用户可将 `.bashrc` 中的别名直接迁移。适合对系统稳定性要求较高的开发者作为日常 Shell 试用。

相关链接：
- 项目地址：[jeff141/meatshell](https://github.com/jeff141/meatshell)

## [edulab](https://github.com/wy51ai/edulab) #3

> 一个基于 Web 的在线实验教学管理平台，教师可创建实验任务、学生在线提交代码，系统自动评分并提供反馈。纯 HTML + JavaScript 前端，后端使用 Node.js。

在远程教育场景下，实验课一直是痛点：需部署本地环境、人工批改效率低。**edulab** 提供一站式解决方案，支持 **C**、**Python**、**Java** 等常见语言的自动评测。教师通过拖拽式编辑器配置测试用例，学生直接在网页编辑器中编写代码并运行。

<p><img src="https://opengraph.githubassets.com/1/wy51ai/edulab" alt="edulab" style="max-width:100%;border-radius:8px;"></p>

目前 Star 数 71，Forks 24，被多个高校的实验课程采用。系统内置防作弊机制（代码相似度检测），并支持 Docker 隔离执行环境，保证评测安全性。前台界面采用响应式设计，移动端可用。

相比 **CodeGrade** 等商业产品，edulab 完全开源、自托管，适合预算有限的大学和培训机构快速搭建私有实验平台。

相关链接：
- 项目地址：[wy51ai/edulab](https://github.com/wy51ai/edulab)

## [sprite-lab](https://github.com/boona13/sprite-lab) #4

> 一个基于 Web 的像素精灵编辑器，用 TypeScript 编写，支持在浏览器中绘制、动画帧编辑，并可直接导出为 PNG 精灵表或游戏引擎格式（如 Unity、Godot）。

独立游戏开发者常需要快速制作像素动画，但专业工具如 **Aseprite** 需付费（20 美元）。**sprite-lab** 完全免费且开源，无需安装，打开浏览器即可使用。核心功能包括：图层、调色板管理、洋葱皮动画预览、导出精灵表。

<p><img src="https://opengraph.githubassets.com/1/boona13/sprite-lab" alt="sprite-lab" style="max-width:100%;border-radius:8px;"></p>

当前版本（v0.5）已支持最多 64x64 像素画布、16 帧动画。社区 Star 67，Forks 7，开发者持续增加对 **Aseprite** 文件格式的兼容性导入。基于 Canvas API 实现，性能良好。

与 **Piskel** 等同类工具相比，sprite-lab 的亮点在于“纯前端 + 现代化 UI”，无后端依赖，适合直接集成到游戏开发工作流中。

相关链接：
- 项目地址：[boona13/sprite-lab](https://github.com/boona13/sprite-lab)

## [papernews](https://github.com/marcj/papernews) #5

> 一个 Python 命令行工具，从指定新闻网站抓取文章，自动排版并生成类似报纸版式的 PDF 简报。支持多源聚合、摘要提取与自定义样式。

信息过载时代，许多用户希望每天收到一份“精选简报”而非无尽推送。**papernews** 实现了一个轻量级管道：先通过 `requests` + `BeautifulSoup` 抓取 RSS 或网页正文，再用 `textwrap` 和 `ReportLab` 生成多栏 PDF。

<p><img src="https://opengraph.githubassets.com/1/marcj/papernews" alt="papernews" style="max-width:100%;border-radius:8px;"></p>

目前支持 **Hacker News**、**Ars Technica**、**The Verge** 等 10 余个站点，用户可通过 YAML 配置文件扩展。项目 Star 53，Forks 5，适合个人或小团队内部使用。输出 PDF 可设置字体、页眉页脚，支持中英文混排。

与 **Calibre** 的新闻下载功能相比，papernews 更专注于“报纸风格”排版，并保留了命令行可脚本化的优势，可结合 `cron` 每日自动发送到邮箱。

相关链接：
- 项目地址：[marcj/papernews](https://github.com/marcj/papernews)

## [ai-shortVideo-pipeline](https://github.com/myccarl/ai-shortVideo-pipeline) #6

> 一个全自动短视频生成流水线，输入文案主题，AI 自动撰写脚本、生成配音、挑选背景视频片段、添加字幕，最终输出 MP4 文件。基于 LangChain + OpenAI + FFmpeg。

短视频自媒体内容创作门槛高，重复性剪辑工作耗时。**ai-shortVideo-pipeline** 试图实现“从标题到成品”一步到位：调用大语言模型生成口播文案，利用 TTS（如 **Edge-TTS**）转语音，再从素材库或 Pexels 下载匹配背景视频，最后通过 FFmpeg 合成。

<p><img src="https://opengraph.githubassets.com/1/myccarl/ai-shortVideo-pipeline" alt="ai-shortVideo-pipeline" style="max-width:100%;border-radius:8px;"></p>

当前 Star 12，处于早期阶段，但已有完整流程演示。支持自定义 OpenAI API Key、选择配音速度与背景音乐。输出视频分辨率为 1080x1920（竖屏），适合抖音、TikTok 等平台。

相比 **Pictory** 等 SaaS 产品，ai-shortVideo-pipeline 完全本地运行，隐私可控，开发者可自由替换其中 AI 模型（如改用本地 LLM）。适合有编程基础的创作者进行二次开发。

相关链接：
- 项目地址：[myccarl/ai-shortVideo-pipeline](https://github.com/myccarl/ai-shortVideo-pipeline)
