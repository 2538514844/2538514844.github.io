## [baoyu-design](https://github.com/JimLiu/baoyu-design) #1

> 一款面向中后台场景的低代码设计系统，提供开箱即用的 UI 组件和主题定制能力。基于 React 生态，帮助开发者快速构建企业级管理界面。

**JimLiu** 团队推出的 **baoyu-design** 定位于填补低代码平台与专业设计系统之间的空白。许多团队在开发后台时重复造轮子，baoyu-design 试图通过统一的设计语言和组件库解决这一痛点。

项目基于 **React** 和 **TypeScript** 开发，内置超过 40 个常用组件，包括表格、表单、对话框、图表等。支持按需加载和全局主题变量覆盖，开发者可以通过 JSON 配置快速定制品牌色、圆角、间距。

<p><img src="https://opengraph.githubassets.com/1/JimLiu/baoyu-design" alt="baoyu-design" style="max-width:100%;border-radius:8px;"></p>

该项目在 GitHub 上已获得 **300 Stars** 和 **19 Forks**，受到社区一定关注。根据文档描述，其组件设计遵循 **WAI-ARIA** 无障碍规范，适合需要高可及性的企业级应用。

与 **Ant Design**、**Element Plus** 等成熟方案相比，baoyu-design 更侧重低代码场景的灵活性——组件支持通过 JSON Schema 驱动渲染，可直接对接后端 API 接口。适合快速原型开发或作为内部管理系统的 UI 底座。

- 项目地址：[JimLiu/baoyu-design](https://github.com/JimLiu/baoyu-design)

## [grok-reg-tool](https://github.com/FengZi1221/grok-reg-tool) #2

> X 平台（原 Twitter）自动化注册辅助工具，基于 TypeScript 开发，集成代理轮换与验证码识别功能。旨在帮助用户批量创建账号。

**FengZi1221** 开发的 **grok-reg-tool** 是一个面向社交媒体自动化操作的工具。随着 X 平台加强新用户注册限制，该工具试图通过模拟浏览器行为、切换 IP 代理以及接入打码平台来绕过风控。

核心功能包括：自动填写注册表单、邮箱验证码自动提取、动态 User-Agent 轮换。项目使用 `puppeteer` 或 `playwright` 进行浏览器自动化，并支持配置第三方打码服务（如 2Captcha）解决 reCAPTCHA 挑战。

<p><img src="https://opengraph.githubassets.com/1/FengZi1221/grok-reg-tool" alt="grok-reg-tool" style="max-width:100%;border-radius:8px;"></p>

目前仓库收获 **38 Stars** 和 **13 Forks**，代码注释较为详细。开发者提供了 `config.ts` 模板，用户只需修改代理列表和打码 API 密钥即可运行。

需要注意，此类工具可能违反 X 平台服务条款，存在账号被封禁的风险。项目仓库已声明“仅用于学习研究”，不建议用于商业批量注册。

- 项目地址：[FengZi1221/grok-reg-tool](https://github.com/FengZi1221/grok-reg-tool)

## [GordenSuperPPTSkills](https://github.com/GordenSun/GordenSuperPPTSkills) #4

> 一套集成 AI 能力的 PPT 制作工具集，支持自然语言生成大纲、自动匹配模板和图表。基于 Python 开发，适合快速生成演示文稿。

**GordenSun** 开发 **GordenSuperPPTSkills** 的初衷是解决职场人士制作 PPT 的重复劳动。它整合了 **OpenAI API** 以及 **python-pptx** 库，用户只需输入主题或关键词，即可生成包含文字、图表和排版的多页 PPT。

工作流程分为三步：AI 生成文案大纲（支持自定义语气和长度）；从内置库或用户上传的模板中选择版式；自动填充内容并生成 `.pptx` 文件。项目还支持批量生成多份风格一致的 PPT。

<p><img src="https://opengraph.githubassets.com/1/GordenSun/GordenSuperPPTSkills" alt="GordenSuperPPTSkills" style="max-width:100%;border-radius:8px;"></p>

GitHub 上已有 **17 Stars** 和 **5 Forks**，代码量约 2000 行。开发者提供了命令行接口（CLI）以及简单的 Web 界面，降低使用门槛。已测试支持 **PowerPoint 2016+** 和 **WPS Office**。

与同类工具（如 **Gamma.app**、**Beautiful.ai**）相比，GordenSuperPPTSkills 完全本地运行（需要 API key），隐私性更好。但模板库相对较少，用户需要自行设计高质量模板来获得更好的输出效果。

- 项目地址：[GordenSun/GordenSuperPPTSkills](https://github.com/GordenSun/GordenSuperPPTSkills)

## [roblox-fps-unlocker](https://github.com/danieljonata-dev/roblox-fps-unlocker) #5

> 一款专为 Roblox 设计的性能优化工具，通过修改本地配置解除帧率上限，支持高达 240 FPS 甚至更高。由 **C++** 编写，轻量且免安装。

Roblox 默认将帧率锁定在 **60 FPS**，对于高刷新率显示器的玩家来说体验不够丝滑。**danieljonata-dev** 开发的 **roblox-fps-unlocker** 通过注入 Hook 修改 Roblox 客户端渲染设置，解除这一限制。

工具采用 **DLL 注入** 方式运行，启动后自动检测 Roblox 进程，并在后台修改 DirectX/FPS 计数器。支持自定义目标帧率（如 144、240、无限制）。并提供了关闭逻辑，退出游戏后自动复原。

<p><img src="https://opengraph.githubassets.com/1/danieljonata-dev/roblox-fps-unlocker" alt="roblox-fps-unlocker" style="max-width:100%;border-radius:8px;"></p>

该项目在 GitHub 上获得 **16 Stars**，代码开源且无闭源二进制文件。开发者声明此工具不修改游戏内存或封包，仅调整显示参数，理论上符合 Roblox 服务条款（类似官方开发者模式）。

不过需注意，部分反作弊系统可能误报此类注入工具为异常。建议用户在单人模式或已验证的服务器中使用。未来计划支持 **Linux** 平台（通过 Wine 运行 Roblox 时的解锁）。

- 项目地址：[danieljonata-dev/roblox-fps-unlocker](https://github.com/danieljonata-dev/roblox-fps-unlocker)

## [fern-core](https://github.com/fern-tui/fern-core) #6

> 基于 Zig 语言开发的下一代终端 UI（TUI）框架，强调零依赖、高性能和内存安全。提供丰富的组件库和灵活的布局系统。

**fern-tui** 团队推出的 **fern-core** 瞄准了 TUI 开发领域，希望替代 **Bubble Tea**（Go）、**Textual**（Python）等方案。选择 **Zig** 作为实现语言，因为 Zig 能直接生成可执行文件，无运行时开销，且内存管理方式更接近底层。

核心特性包括：支持 *flexbox* 布局的网格系统、事件驱动的虚拟 DOM 更新、原生 *Unicode* 渲染（包括表情符号和双宽字符）。所有组件（按钮、输入框、表格等）都是“无状态”的，状态由外部管理，方便单元测试。

<p><img src="https://opengraph.githubassets.com/1/fern-tui/fern-core" alt="fern-core" style="max-width:100%;border-radius:8px;"></p>

目前项目处于 **alpha** 阶段，拥有 **13 Stars**。代码量约 3000 行，提供了基础的 `Hello World` 和 `Todo List` 示例。性能测试显示，在 5000 行数据的表格滚动中，帧率维持在 **120 FPS** 以上。

对于熟悉 **Zig** 语言的开发者，fern-core 是一个很有潜力的底层 TUI 框架。但社区文档尚不完善，且 Zig 本身处于 0.14 开发阶段，短期内恐难商业可用。适合对 TUI 有极致性能追求的前沿开发者。

- 项目地址：[fern-tui/fern-core](https://github.com/fern-tui/fern-core)
