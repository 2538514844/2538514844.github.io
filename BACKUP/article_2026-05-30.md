## [yt-downloader](https://github.com/yuyefeiyu/yt-downloader) #1

> 一款基于 C# 的 YouTube 视频下载工具，支持高画质与字幕保存，操作简单无需复杂配置。专为需要离线观看视频的用户设计。

许多用户希望将 YouTube 视频保存到本地以便离线播放或编辑，但现有工具常存在依赖多、更新慢、画质被压缩等问题。**yt-downloader** 试图用纯 C# 实现一个轻量级解决方案。

项目核心依赖 `youtube-dl` 的 API 封装，提供图形界面和命令行两种模式。用户只需粘贴视频链接，即可选择分辨率（最高 4K）和字幕格式，一键下载。代码结构清晰，便于二次开发。

上线以来已获得 **109** 个 Star，社区反馈积极。虽然 Forks 为零，但作者仍在维护，近期修复了部分 URL 解析错误。项目体积仅 2MB，适合集成到其他应用中。

<p><img src="https://opengraph.githubassets.com/1/yuyefeiyu/yt-downloader" alt="yt-downloader" style="max-width:100%;border-radius:8px;"></p>

与同类工具相比，**yt-downloader** 的优势在于纯 .NET 生态，Windows 用户无需安装 Python 或 Node.js。适用于视频创作者、教育工作者或普通用户备份内容。

相关链接：
- 项目地址：[yuyefeiyu/yt-downloader](https://github.com/yuyefeiyu/yt-downloader)

## [LogicPipe](https://github.com/fxyz666/LogicPipe) #2

> 一个 Python 数据流管道编排框架，通过声明式配置定义复杂的逻辑处理链路。适合 ETL、实时数据处理与微服务编排场景。

数据工程中，任务管道常需要组合多个步骤，但传统方案要么依赖重量级框架（如 Airflow），要么缺乏复用性。**LogicPipe** 提供轻量级管道定义，用 YAML 或代码描述节点、连接与转换规则。

核心功能包括：节点可扩展（支持自定义函数）、并行执行、错误重试与日志追踪。内置常见算子如过滤器、映射器、聚合器。用户可通过装饰器快速注册处理函数。

目前获得 **72** 个 Star，Forks 23，表明社区有一定参与度。项目文档示例丰富，覆盖文件处理、数据库迁移和 API 聚合三大场景。

<p><img src="https://opengraph.githubassets.com/1/fxyz666/LogicPipe" alt="LogicPipe" style="max-width:100%;border-radius:8px;"></p>

与 **Prefect** 或 **Luigi** 相比，**LogicPipe** 更偏重“逻辑”而非“流程”，允许在节点内嵌入复杂条件分支。适合中小规模数据流水线，尤其是团队希望快速验证管道设计的场景。

相关链接：
- 项目地址：[fxyz666/LogicPipe](https://github.com/fxyz666/LogicPipe)

## [parsel](https://github.com/shipfastlabs/parsel) #3

> 一个 PHP 爬虫解析库，提供类似 jQuery 的 DOM 操作语法，简化 HTML/XML 数据提取过程。面向 PHP 生态中的爬虫工程师。

PHP 在爬虫领域的生态相对薄弱，开发者常借助 `DOMDocument` 或正则表达式手动处理，效率低且容易出错。**parsel** 引入链式选择器语法，支持 CSS 选择器和 XPath 解析，与 Python 的 **Parsel** 库设计理念相近。

库核心方法包括 `css()`、`xpath()`、`re()`，返回迭代器支持懒加载。内置编码自动检测、HTML 清理和异常处理。文档以快速上手和 API 参考为主，示例涵盖电商页面抓取。

上线后获 **46** 个 Star，Forks 1。虽然用户基数尚小，但适合 Laravel 项目集成，作者计划未来加入会话管理和缓存支持。

<p><img src="https://opengraph.githubassets.com/1/shipfastlabs/parsel" alt="parsel" style="max-width:100%;border-radius:8px;"></p>

与 **Simple HTML DOM** 等老牌库相比，**parsel** 更现代、类型安全，且不依赖外部扩展。适用于需要快速搭建 PHP 爬虫的工程师，特别是配合 Guzzle 客户端使用。

相关链接：
- 项目地址：[shipfastlabs/parsel](https://github.com/shipfastlabs/parsel)

## [websites-100-audit](https://github.com/Moh4696/websites-100-audit) #4

> 一键运行 Shell 脚本，批量审计 100 个网站的可用性、SSL 证书、加载速度与基本安全配置。适合运维人员做常规巡检。

手动检查多站点状态耗时且容易遗漏，**websites-100-audit** 将常见检查项封装为 Bash 脚本，只需提供 URL 列表即可并行测试。输出结果格式化为表格，便于邮件或日志存档。

脚本使用 `curl`、`openssl`、`nmap` 等系统命令，无额外依赖。检查项包括：HTTP 状态码、响应时间、SSL 过期日期、是否启用 HSTS、CORS 头等。

获得 **44** 个 Star，Forks 8，说明有一定实用性。作者提供 sample 列表，用户可直接替换为自己的站点。脚本运行时间约 2-5 分钟，适合 cron 定时任务。

<p><img src="https://opengraph.githubassets.com/1/Moh4696/websites-100-audit" alt="websites-100-audit" style="max-width:100%;border-radius:8px;"></p>

与 **Checkmk** 或 **Zabbix** 等完整监控方案相比，**websites-100-audit** 更轻量、临时性强，适合没有监控系统的小团队或作为安全渗透测试的前置步骤。

相关链接：
- 项目地址：[Moh4696/websites-100-audit](https://github.com/Moh4696/websites-100-audit)

## [line-oa-mcp-ultimate](https://github.com/wasintoh/line-oa-mcp-ultimate) #5

> TypeScript 实现的 LINE 官方账号消息控制协议（MCP）集成工具，帮助开发者快速搭建消息管理与自动回复服务。

LINE OA 官方 API 允许发送消息、管理粉丝，但协议细节复杂，文档更新慢。**line-oa-mcp-ultimate** 封装了 MCP 签名认证、回调验签、富媒体消息构造等核心环节，提供类型安全接口。

功能包括：群发消息、模板消息推送、用户画像获取、Webhook 事件处理。配置文件支持多账号管理，内置简单的 Rate Limiter 避免触发封禁。

获得 **27** 个 Star，Forks 11，说明有一定社区二次开发价值。示例代码包含 Node.js 与 Deno 双版本，兼容性较好。

<p><img src="https://opengraph.githubassets.com/1/wasintoh/line-oa-mcp-ultimate" alt="line-oa-mcp-ultimate" style="max-width:100%;border-radius:8px;"></p>

与 **LINE Bot SDK** 官方包相比，**line-oa-mcp-ultimate** 更聚焦于“管理”而非“对话”，适合企业运营后台开发。但需注意 LINE 的 MCP 协议逐步被 Messaging API 取代，使用者需关注官方迁移路线。

相关链接：
- 项目地址：[wasintoh/line-oa-mcp-ultimate](https://github.com/wasintoh/line-oa-mcp-ultimate)

## [mainland-tv-drama](https://github.com/ivanzhang2/mainland-tv-drama) #6

> 一个命令行脚本，聚合豆瓣等平台的大陆电视剧评分、热度与观看渠道，辅助用户快速筛选值得追的剧集。

面对大量新剧，观众常陷入选择困难。**mainland-tv-drama** 通过爬取多个源，输出近期最热剧集清单，包含评分、类型、更新状态及播放平台（如腾讯、爱奇艺、优酷）。

核心功能是定期更新榜单，支持按年份、评分过滤，输出 Markdown 或 CSV 格式。目前脚本为 Python 编写，依赖 requests 和 BeautifulSoup。

获得 **15** 个 Star，暂无 Forks，属于小型兴趣项目。作者在 README 中声明仅供学习交流，不提供盗版链接。

<p><img src="https://opengraph.githubassets.com/1/ivanzhang2/mainland-tv-drama" alt="mainland-tv-drama" style="max-width:100%;border-radius:8px;"></p>

与商业追剧 App 相比，**mainland-tv-drama** 透明可控，用户可自定义数据源。适合技术爱好者自建追剧提醒，但数据源变化时需手动维护选择器。

相关链接：
- 项目地址：[ivanzhang2/mainland-tv-drama](https://github.com/ivanzhang2/mainland-tv-drama)
