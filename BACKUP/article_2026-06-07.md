## [image-to-code](https://github.com/yuzhworkhard-wq/image-to-code) #1

> 将设计截图直接转换为 HTML/CSS 代码的开源工具，基于视觉识别与布局分析，大幅缩短前端切图周期。适合设计师与开发者快速原型验证。

<p><img src="https://opengraph.githubassets.com/1/yuzhworkhard-wq/image-to-code" alt="image-to-code" style="max-width:100%;border-radius:8px;"></p>

设计稿转代码一直是前端开发的痛点，手动切图耗时且容易出错。**image-to-code** 尝试用深度学习模型自动识别截图中的元素布局、颜色与字体，输出干净的语义化代码。

项目核心采用 **Python** 实现，后端可接入 **GPT-4V** 或本地视觉模型。用户上传截图后，系统先检测组件边界，再逐块生成对应的 **HTML** 结构与 **CSS** 样式，支持实时预览与导出。

尽管目前仅收获 **94 Stars**，但其思路与 **screenshot-to-code** 等成熟项目类似，且完全开源。开发者表示后续将支持 React/Vue 框架输出，并加入交互元素识别。

适用范围包括：快速生成 Landing Page、组件库示例页面、设计评审阶段的代码原型。相比同类项目，它更聚焦中文 UI 场景的字体与布局适配。

相关链接：
- 项目地址：[yuzhworkhard-wq/image-to-code](https://github.com/yuzhworkhard-wq/image-to-code)

## [Claude-Mythos-AI-App](https://github.com/Anthropic-Claude-Mythos/Claude-Mythos-AI-App) #2

> 一款基于 **Anthropic Claude** 构建的跨平台应用，集成了长上下文理解、图像分析与代码生成能力，面向创作者与开发者提供一站式 AI 助手。

<p><img src="https://opengraph.githubassets.com/1/Anthropic-Claude-Mythos/Claude-Mythos-AI-App" alt="Claude-Mythos-AI-App" style="max-width:100%;border-radius:8px;"></p>

随着 **Claude** 系列模型在长文档理解与多模态上的突破，社区涌现出大量封装应用。**Claude-Mythos-AI-App** 将多个 API 功能整合进一个桌面界面，支持拖入图片、PDF 直接提问。

项目使用 **C#** 和 **.NET MAUI** 开发，实现了 Windows/macOS 原生体验。用户可通过自定义 `system prompt` 切换写作、编程、翻译等模式，并保存对话历史本地加密存储。

目前仓库有 **34 Stars**，尚处于早期版本。开发者计划加入插件系统与语音输入，使其成为 Claude 的“私房版” ChatGPT。对于需要频繁与 Claude 交互的用户来说，免去了每次打开网页的麻烦。

同类应用如 **Claude Desktop** 官方版已推出，但闭源。**Claude-Mythos** 的优势在于开源可定制，且内置了 **Mythos** 风格的角色预设模板。

相关链接：
- 项目地址：[Anthropic-Claude-Mythos/Claude-Mythos-AI-App](https://github.com/Anthropic-Claude-Mythos/Claude-Mythos-AI-App)

## [DualSenseX-Steam-PC-Controller](https://github.com/PWMH4/DualSenseX-Steam-PC-Controller) #3

> 让 **PlayStation DualSense** 手柄在 **Steam** 游戏上完美模拟 Xbox 输入，并支持自适应扳机与触觉反馈的 PC 工具。无需额外硬件即可享受原生手柄体验。

<p><img src="https://opengraph.githubassets.com/1/PWMH4/DualSenseX-Steam-PC-Controller" alt="DualSenseX-Steam-PC-Controller" style="max-width:100%;border-radius:8px;"></p>

PC 玩家使用 DualSense 手柄时，常遇到按键映射错乱或高级功能无法启用的问题。**DualSenseX** 通过拦截 **Steam Input** 层，将 PS5 手柄识别为 Xbox 控制器，同时保留索尼独有的自适应扳机特性。

项目基于 **C#** 开发，利用 **HidLibrary** 与 **ViGEmBus** 驱动实现底层通信。安装后自动注入配置，用户无需每次手动切换模式。支持无线蓝牙与有线连接，延迟控制在 **5ms** 以内。

虽然只有 **33 Stars**，但该工具解决了小众痛点。对比商业软件 **DS4Windows**，它更专注于 Steam 生态环境，且开源允许社区提交游戏专属配置表。

未来计划包括支持 **PS4 DualShock** 以及 **Nintendo Switch Pro** 手柄，力图成为 Steam 手柄通用适配器。

相关链接：
- 项目地址：[PWMH4/DualSenseX-Steam-PC-Controller](https://github.com/PWMH4/DualSenseX-Steam-PC-Controller)

## [LiteDoc](https://github.com/0xovo/LiteDoc) #4

> 一个百 KB 级别的静态文档生成器，只需一个 Markdown 文件和一行命令即可生成响应式站点。专为个人笔记、API 文档与说明书设计。

<p><img src="https://opengraph.githubassets.com/1/0xovo/LiteDoc" alt="LiteDoc" style="max-width:100%;border-radius:8px;"></p>

在 **Docusaurus**、**MkDocs** 等功能强大的文档工具动辄需要复杂配置的背景下，**LiteDoc** 选择极简路线。它将所有内容集中于单个 HTML 文件中，通过前端 JavaScript 解析 Markdown 并渲染目录树。

核心采用 **HTML** + **JavaScript** 纯静态方案，无构建步骤。用户只需编写 `docs.md` 并用 `python3 -m http.server` 运行即可。支持代码高亮、数学公式与暗色主题，所有样式内联，仅 **15KB**。

目前获 **25 Stars**，但因其零依赖特性，适合嵌入到小型开源项目作为内置文档页面。对比同类 **docsify**，LiteDoc 无需 Node.js 环境，对初学者更友好。

开发者在 README 中承诺后续增加多语言切换与搜索功能，并保持单文件体积不变。

相关链接：
- 项目地址：[0xovo/LiteDoc](https://github.com/0xovo/LiteDoc)

## [natural-chinese-copy-core](https://github.com/wwtlitee/natural-chinese-copy-core) #5

> 中文自然语言复制核心库，提供同义替换、句式变换与风格迁移功能，帮助内容创作者快速改写文本并保持语义流畅。

<p><img src="https://opengraph.githubassets.com/1/wwtlitee/natural-chinese-copy-core" alt="natural-chinese-copy-core" style="max-width:100%;border-radius:8px;"></p>

在内容营销与 SEO 领域，经常需要对同一段话进行多版本改写以避免重复。**natural-chinese-copy-core** 利用 **NLP** 模型（基于 BERT 与 GPT 蒸馏），实现词级替换与句级重构，输出自然的中文表达。

项目以 **JavaScript** 模块形式发布，支持浏览器与 Node.js 环境。核心 API 仅两个函数：`rewrite(text, style)` 和 `paraphrase(text, ratio)`，用户可指定“正式/口语/简洁”三种风格。

尽管只有 **23 Stars**，但它的语义保留度测试结果不错——在 **20** 句测试中平均 **85%** 的改写句保持了原意。同类工具如 **TextBlob** 对中文支持薄弱，此项目填补了空白。

适用场景包括：文章洗稿检测的对抗训练、自媒体内容批量生成、外语翻译的中文润色。开发者计划加入**多轮对话改写**与**关键词强制保留**功能。

相关链接：
- 项目地址：[wwtlitee/natural-chinese-copy-core](https://github.com/wwtlitee/natural-chinese-copy-core)

## [ComfyUI-BerniniStudio](https://github.com/CCpt5/ComfyUI-BerniniStudio) #6

> 为 **ComfyUI** 打造的 **3D 生成工作流节点**，集成 **Bernini** 模型，允许用户从文本或图片直接生成可导出的三维网格。

<p><img src="https://opengraph.githubassets.com/1/CCpt5/ComfyUI-BerniniStudio" alt="ComfyUI-BerniniStudio" style="max-width:100%;border-radius:8px;"></p>

**ComfyUI** 作为 Stable Diffusion 最流行的节点式工作台，已从图像扩展至视频、音频乃至 3D 生成。**ComfyUI-BerniniStudio** 将 **Bernini**（一种基于 NeRF 的单一图片重建 3D 模型）打包成可拖拽节点，降低用户使用门槛。

项目以 **JavaScript** 编写，遵循 ComfyUI 插件规范。安装后，用户可在节点列表中看到“Bernini Image to 3D”节点，支持设置分辨率、密度阈值与纹理映射，输出 `GLB` 或 `OBJ` 格式。

目前 **22 Stars**，但展现了 3D AIGC 与 ComfyUI 生态融合的趋势。同类插件如 **ComfyUI-3D-Pack** 需要额外安装 CUDA 依赖，而此项目将所有推理逻辑封装在 **ONNX Runtime** 中，跨平台兼容性更好。

应用场景包括：游戏资产快速生成、3D 打印原型验证、AR 内容制作。开发者后续将加入多视图生成与动画骨骼绑定。

相关链接：
- 项目地址：[CCpt5/ComfyUI-BerniniStudio](https://github.com/CCpt5/ComfyUI-BerniniStudio)
